Laboratorio

Web

Il laboratorio sul Web mi ha aiutato a comprendere l'intera catena di comunicazione che si attiva ad ogni click del browser. Ho compreso che un'applicazione web non è solo interfaccia grafica, ma il risultato del coordinamento rigoroso tra protocolli applicativi, servizi di risoluzione dei nomi e architetture distribuite.

🔁

HTTP, HTTPS e DNS

Ho analizzato il meccanismo di Richiesta/Risposta del protocollo HTTP e l'importanza del protocollo crittografato HTTPS. Ho studiato il ruolo dei server DNS nella traduzione ricorsiva dei nomi di dominio in indirizzi IP instradabili.

🧭

Modello Client-Server

Ho approfondito la netta separazione tra il ruolo del Client (responsabile del rendering e dell'interazione dell'utente) e del Server (deputato all'elaborazione delle logiche di business, alla gestione dello stato e alle interrogazioni ai database).

🎨

Linguaggi del Web

Ho consolidato l'uso di HTML per la definizione strutturale e semantica dei contenuti, e di CSS per il layout responsivo (Media Queries). Abbiamo discusso il ruolo dei linguaggi di scripting (come JavaScript) per rendere dinamiche le interfacce utente.

Cosa ho imparato

  • L'architettura del World Wide Web si fonda su standard aperti e protocolli applicativi strutturati del livello 7 della pila ISO/OSI.
  • Il funzionamento di HTTP (metodi GET, POST, codici di stato) è essenziale sia per lo sviluppo sia per l'analisi delle vulnerabilità web.
  • La comprensione delle tecnologie Client-Server mi ha fornito le basi logiche per implementare questo stesso sito web di presentazione.
